# C3 第一阶段结果：标签层面门限未通过（%Y-%m-%d %H:%M）

## 数字

教师只在 L（3,800 帧，官方 train 的 21.1%）上训练 100 轮，验证集 mAP@0.5:0.95：

| 教师 | val mAP@0.5:0.95 |
|---|---|
| 早期融合 | 0.3788 |
| 中到晚期融合 | 0.4132 |
| 晚期融合 | 0.4065 |
| **三教师 WBF（验证集选出的元组）** | **0.4045** |

WBF 元组 {'iou': 0.55, 'mode': 'weighted', 'min_models': 2, 'post_conf': 0.03}，在 72 组配置中选出。

把该元组原样应用到 U（14,190 帧，343,329 个融合框），对同一批框做三种打分，按 U 的留出人工标签评估：

| 打分 | mAP@0.5 | mAP@0.5:0.95 |
|---|---|---|
| 纯 WBF 聚合分 | 0.6060 | 0.4071 |
| 仅置信度 | 0.5884 | 0.4016 |
| 式 3 | 0.5921 | 0.4041 |

- 式 3 减纯 WBF：**-0.29 pp**（门限要求 ≥ +0.30 pp）→ **未通过**
- 式 3 减仅置信度：**+0.25 pp**（这是结构项的净贡献）

## 两点解读

**一、结构项确实有贡献，但很小。** 式 3 比仅置信度高 0.25 pp。反无人机数据上这个数是 +0.46 pp（night-160），同样很小且在种子噪声内。两个数据集给出一致的结论：结构项有作用，但不大。

**二、更要紧的是共识本身不成立。** 三教师 WBF 在验证集上是 0.4045，低于最好的单教师（中到晚期 0.4132）。也就是说这个教师池的共识还不如直接用最好的那个教师。而 RA-CMCD 的整个前提是「共识携带了值得迁移的定位证据」。前提在这个池上不成立，后面的加权自然无从谈起。

对照六月那批五个融合算子教师（在全部标注上训练）：纯 WBF 0.7184 高于每一个单教师（0.6909 到 0.7060）。差别在池的构成，不在方法。

## 诊断

我选的三个教师是同一骨干的三种融合深度，其中早期融合比另外两个低 3.4 pp，把共识拖下来了。反无人机的教师池是三个**不同架构**（YOLO11-RGBT、C2Former、CFT），彼此水平相当（val 0.61 / 0.56 / 0.55）。异构性不够、强弱不均，是这次共识失效的直接原因。

另外，被选中的 WBF 元组用的是 weighted 模式，其聚合分本身已经包含置信度乘先验再按支持度求和——已经做了式 3 大部分的事。式 3 要在这个基线之上再提升，本来就难。

## 门限的适用边界

需要说明：这个门限测的是**排序质量**（同一批框换打分后 mAP 变化），而论文的主张是**训练权重**（伪标签逐框加权对学生的影响）。二者不是一回事，均一训练权重不等于均一排序分。所以门限未通过不能直接否定论文的主张，但也确实没有为它提供支持。

## 三个选择

- **A 就此停下**，把这个负面结果如实写进论文，作为方法的边界条件：共识蒸馏要求教师池的共识优于其最好成员，本次在 DroneVehicle 的融合深度教师池上不满足。诚实，但无助于创新性质疑。
- **B 重建教师池再跑一次门限**（约 3 到 4 GPU 小时）：去掉早期融合，改用 DroneVehicle 项目自己的融合算子（MCWF、gated、attention）在 L 上重训。六月的证据表明这组算子的共识能超过单教师。若重建后共识仍不成立，那就是确定的答案。
- **C 跳过门限直接训学生**（2.5 到 4 GPU 日）：理由是门限测的不是论文的主张。但在共识本身不优于最好单教师的池上训学生，结果大概率难看。

我倾向 B：成本只有学生阶段的零头，且直接针对诊断出的原因。若 B 之后共识成立，再按原计划进学生阶段；若仍不成立，A 就是最终答案，而且届时的负面结论有两组教师池支撑，比现在这一组更有说服力。
